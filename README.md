# Diff two texts faster

A fast drop-in for makefun-diff 1.0.0: `solve.js` returns exactly the same patch string for every
`{ old, new }` pair, computed with integer-interned lines and a typed-array Myers search.
`main.ts` is the harness driver that reads the cases and writes the answers.
